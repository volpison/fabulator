# Fabulator

**Pre-production writing suite.**

Fabulator is where a project is planned and written down *before* it is made. It keeps the whole world of a story in one place (characters, places, notes, continuity, a timeline) and lets you write it as a **Novel**, a **Comic** or a **Screenplay**. A fourth mode, **Game Prototyping** (side-quests and conditional rules), is planned. It plans and writes; it does not produce images, video or audio.

## What you can do

- **Plan on a Timeline, write in a Manuscript.** Chapters and scenes, comic issues and pages, or screenplay acts and scenes, laid out the way you think about them.
- **Write in three modes.** Novel prose; comics in plot-first or full-script style; screenplays with slug lines, dialogue, automatic CONT'D and a page count.
- **Keep your world straight.** Characters and places with aliases, `@` mentions, a Cast grid of who appears where, plotlines, story time, scene notes and to-dos.
- **Never lose work.** Autosave, atomic writes, rotating backups, crash recovery, and a Snapshots history of every scene or page (deleted ones can come back).
- **Find and change things.** Project-wide Search, Find & replace with an undo trail, word-count goals.
- **Get it out.** Word, EPUB, PDF, Fountain, comic scripts and thumbnail sheets, plain text, or a Markdown folder you can keep in git.
- **Make it yours.** Colour themes (import VS Code and Base16 themes), focus and typewriter modes.

## Run

```bash
npm install
npm run tauri dev
```
