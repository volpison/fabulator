# Getting started

## Install and run

Fabulator is a desktop app (Tauri 2). To run it from the source:

```bash
npm install
npm run tauri dev
```

Windows installers are built from release tags; the installer is not code-signed, so Windows SmartScreen may warn on first run (choose *More info*, then *Run anyway*).

## Your first story

- A new session starts with an empty story: one chapter, one plotline and one empty scene.
- **File → New story** (Ctrl+N) starts another novel. **File → New comic** and **File → New screenplay** start those modes.
- **File → Load sample story** opens "The Boy Who Cried Wolf", a small novel to look around in.
- Save with **Ctrl+S**. Your work is also saved automatically while you write; see [Safety, backups and recovery](safety-and-backups.md).

## Where things are

- **Timeline** (Ctrl+1) plans the structure: chapters and scenes, issues and pages, or acts and scenes. **Manuscript** (Ctrl+2) is where you write. **Cast** (Ctrl+3) shows who appears where.
- The side panels hold your **Characters**, **Places**, **Abilities** and **Notes**.
- **Search** (Ctrl+F), **Find & replace** (Ctrl+H), **Snapshots** and **Export** (Ctrl+E) are in the menus and in [Shared tools](shared-tools.md) and [Export](export.md).
