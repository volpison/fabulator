# Example colour themes

Import any of these from **View → Theme → Import…**:

- `*.json` are Fabulator theme files (see "Colour themes" in the main README).
- `*.base16.yaml` is a standard Base16 scheme; thousands exist online and all import the same way.

These only list the published base colours of each palette (the rest is derived and checked for readability).
The original palettes are, as far as I know, MIT-licensed; check each project's licence before redistributing them.
